# Tableau Data Visualisation Project | Data Technician Bootcamp

## 🚀 Overview

This project showcases the Tableau skills developed during my **Data Technician Bootcamp** through a range of hands-on data visualisation and dashboarding exercises. Working with retail, sales, customer, geographic, and business datasets, I transformed raw data into interactive dashboards that support data exploration and decision-making.

The project focused on creating impactful visual stories using interactive dashboards, calculated fields, filters, and multiple chart types to uncover trends, patterns, and key insights.

## 💡 Project Highlights

### 🇬🇧 GB Employment Dashboard

- Developed an interactive dashboard to analyse employment trends across Great Britain
- Visualised regional employment patterns using map-based visualisations
- Utilised filters and interactive controls to compare locations and employment metrics
- Enabled users to explore workforce trends and identify regional variations through dynamic dashboards

### 🌍 Global Health Dashboard

- Built an interactive dashboard exploring key health indicators across countries and continents
- Analysed metrics such as population, life expectancy, and healthcare outcomes
- Combined maps, line charts, and filters to reveal trends and comparisons over time
- Presented complex global datasets through clear and engaging visualisations

### 🎵 Spotify Trends Dashboard

- Designed an interactive dashboard to explore music trends and track characteristics
- Analysed metrics including popularity, danceability, energy, and genre performance
- Used interactive filters and visualisations to identify patterns in listening behaviour
- Created a data-driven story highlighting trends across artists, genres, and songs
